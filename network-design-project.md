# Three-Floor Office Network Design

**Project Type:** Network Infrastructure Design  
**Security Domain:** Network Infrastructure & Security  
**Tools & Technologies:** Cisco Switches, VLANs, Windows Server, Active Directory, Wireless Networking

---

## 1. Scenario & Objective

This project involved designing a network infrastructure for a three-floor office building for Primatech Solutions Inc.

The objective was to develop a reliable, secure, and scalable network supporting multiple departments, servers, wireless access points, and shared resources.

## 3. Methodology & Execution

### Network Planning
- Identified networking requirements for a three-floor office.
- Planned the placement of network equipment in the MDF and IDFs.
- Selected Cisco Catalyst 9200L switches for network connectivity.
- Designed a network architecture supporting multiple departments.

### Server Infrastructure
- Planned two Windows Server domain controllers for redundancy.
- Included a dedicated storage server with 30 TB of storage.
- Designed server infrastructure to support authentication, file sharing, and network services.

### Network Security
- Planned VLAN segmentation to separate departments and network traffic.
- Incorporated wireless authentication using RADIUS.
- Included redundant routers to improve network availability.

### Documentation
- Created network diagrams showing equipment placement and connectivity.
- Documented hardware selections and network infrastructure requirements.
- Considered scalability, reliability, and future expansion.

### Results
